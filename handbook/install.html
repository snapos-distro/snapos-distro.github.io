Installing by hand

With the SnapOS minimal USB, the NixOS way.

The disk, install and restart steps on this page are typed by a virtual machine in the SnapOS test repository on every change to the minimal USB.

  1. Start the minimal USB

    Flash the minimal image with balenaEtcher and start the computer from it. You get a terminal, already logged in. Commands that change the disk need sudo.

  2. Connect to the internet

    A cable works by itself. For Wi-Fi:

    nmtui

    Choose Activate a connection, pick your network, type the password. Check with ping -c 2 nixos.org.

  3. Partition the disk

    Find your disk (a disk of the right size; vda, sda or nvme0n1):

    lsblk

    Then make two partitions: a small one to start the computer, and the rest for SnapOS. This erases the disk. With the disk /dev/sda:

    sudo parted -s /dev/sda -- mklabel gpt \
  mkpart ESP fat32 1MiB 512MiB set 1 esp on \
  mkpart root ext4 512MiB 100%

  4. Format and mount

    sudo mkfs.fat -F 32 -n boot /dev/sda1
sudo mkfs.ext4 -L nixos /dev/sda2
sudo mount /dev/disk/by-label/nixos /mnt
sudo mkdir -p /mnt/boot
sudo mount -o umask=077 /dev/disk/by-label/boot /mnt/boot

    On an NVMe disk the partitions are /dev/nvme0n1p1 and /dev/nvme0n1p2.

  5. Prepare SnapOS

    snapos init

    This detects your hardware and puts the SnapOS files in /mnt/etc/snapos. In NixOS the same step is nixos-generate-config --root /mnt.

  6. Choose

    sudo nano /mnt/etc/snapos/local.nix

    This small file is your system: its name, time zone, language, keyboard, desktop, look and your user.

    networking.hostName = "snapos";
time.timeZone = "America/Sao_Paulo";
i18n.defaultLocale = "pt_BR.UTF-8";
console.keyMap = "br-abnt2";
services.xserver.xkb.layout = "br";
snapos.desktop = "xfce";        # budgie, plasma, xfce or hyprland
snapos.appearance = "dark";     # dark or light
users.users.ana = { isNormalUser = true; extraGroups = [ "wheel" "networkmanager" ]; };

    Save with Ctrl+O, close with Ctrl+X.

  7. Install

    snapos install

    SnapOS builds the system described in the files and downloads what it needs, then asks a password for each user. In NixOS this is nixos-install --flake.

  8. Restart

    reboot

    Remove the USB stick. SnapOS starts, and the same files now live in /etc/snapos: change them any time and apply with snapos rebuild.
