Handbook: Installing by hand

The disk, install and restart steps below are typed by a virtual machine in the SnapOS test repository on every change to the minimal USB.

About the minimal USB

The minimal USB starts in a terminal, already logged in, with no installer asking questions. It is the SnapOS version of the NixOS minimal ISO: you prepare the disk yourself, describe the system you want in a file, and SnapOS builds it. The result is the same SnapOS the installer gives you. Commands that change the disk need sudo.

Get it on the Downloads page and flash it with balenaEtcher.

Starting the USB

Start the computer from the USB stick (often F12, F9 or Esc while it turns on). The screen shows the steps of this page and the address of this handbook.

Configuring the network

A network cable works by itself. For Wi-Fi, open the network tool, choose Activate a connection, pick your network and type the password:

nmtui

Check that the internet works:

ping -c 2 nixos.org

Preparing the disks

List the disks and find yours by its size. It is usually sda, vda or nvme0n1:

lsblk
The next command erases the whole disk.

Make two partitions: a small one (512 MB) the computer starts from, and the rest for SnapOS. With the disk /dev/sda:

sudo parted -s /dev/sda -- mklabel gpt \
  mkpart ESP fat32 1MiB 512MiB set 1 esp on \
  mkpart root ext4 512MiB 100%
PartitionSizeFor
/dev/sda1512 MBstarting the computer (EFI)
/dev/sda2the restSnapOS and your files

Formatting and mounting

Give each partition a file system and a label, then mount the new system at /mnt:

sudo mkfs.fat -F 32 -n boot /dev/sda1
sudo mkfs.ext4 -L nixos /dev/sda2
sudo mount /dev/disk/by-label/nixos /mnt
sudo mkdir -p /mnt/boot
sudo mount -o umask=077 /dev/disk/by-label/boot /mnt/boot

On an NVMe disk the partitions are /dev/nvme0n1p1 and /dev/nvme0n1p2.

Preparing SnapOS

snapos init

This detects your hardware and puts the SnapOS files in /mnt/etc/snapos, with a local.nix for your choices. In NixOS this step is nixos-generate-config --root /mnt.

Choosing your system

sudo nano /mnt/etc/snapos/local.nix

This small file is your system. Change the values you want:

networking.hostName = "snapos";
time.timeZone = "America/Sao_Paulo";
i18n.defaultLocale = "pt_BR.UTF-8";
console.keyMap = "br-abnt2";
services.xserver.xkb.layout = "br";
snapos.desktop = "xfce";        # budgie, plasma, xfce or hyprland
snapos.appearance = "dark";     # dark or light
users.users.ana = {
  isNormalUser = true;
  extraGroups = [ "wheel" "networkmanager" ];
};

Save with Ctrl+O and close with Ctrl+X. The other files in /mnt/etc/snapos are SnapOS itself; you do not need to touch them.

Installing

snapos install

SnapOS builds the system described in the files, downloading what it needs, then asks a password for each user. In NixOS this is nixos-install --flake.

Restarting

reboot

Remove the USB stick. SnapOS starts, and your files now live in /etc/snapos: change them any time and apply with snapos rebuild. Next: Working with SnapOS →
