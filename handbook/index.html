The SnapOS handbook

Install SnapOS by hand, then live with it.

The handbook follows what you do with the minimal USB: a terminal and no installer with questions. You partition the disk, describe the system you want in one file, and SnapOS builds it. Everything you learn here is how NixOS works too.

1. Installing by hand

Connect, partition, format, mount, snapos init, choose, snapos install.

2. Living with SnapOS

Programs, changes, undo, updates, SnapGuard and .deb files.
