Handbook: Working with your system

Every change is a line in a file in /etc/nixos, and every change can be undone. Each task shows the NixOS command and, if you added the commands pack, the snapos one.

Changing the system

Edit a file, then apply it:

TaskNixOSWith the commands pack
edit the systemsudo nano /etc/nixos/configuration.nixsnapos config
see what would changenixos-rebuild build --flake /etc/nixos#mypcsnapos diff
apply nowsudo nixos-rebuild switch --flake /etc/nixos#mypcsnapos rebuild
apply at the next startsudo nixos-rebuild boot --flake /etc/nixos#mypcsnapos rebuild --next-boot

Programs

TaskNixOSWith the commands pack
searchnix search nixpkgs vlcsnapos find vlc
installadd vlc to the list, rebuildsnapos add vlc
removeremove it from the list, rebuildsnapos remove vlc
use once, without installingnix shell nixpkgs#vlcsnapos shell vlc

Updates

Everything comes from the inputs in flake.lock. To move them all forward and build the result for the next start:

cd /etc/nixos
sudo nix flake update
sudo nixos-rebuild boot --flake /etc/nixos#mypc

With the updater pack, SnapOS tells you at login when there is a new SnapOS release and snapos update moves only the snapos input, with the guard that undoes a failed start.

Undoing

Each rebuild keeps the previous system as a generation, listed in the boot menu.

TaskNixOSWith the commands pack
list themnixos-rebuild list-generationssnapos generations
go backsudo nixos-rebuild switch --rollbacksnapos rollback
free spacesudo nix-collect-garbage --delete-older-than 14dsnapos gc

SnapGuard and .deb files

snapguard scan ~/Downloads   # scan a folder
snapguard status             # engine and real-time protection
snap-deb program.deb         # scanned, then installed in the Debian layer

When something breaks

sudo nixos-rebuild switch --flake /etc/nixos#mypc --show-trace   # the full error
snapos doctor    # graphics, boot, network and antivirus (commands pack)
snapos log       # the output of the last rebuild

If the system does not start, pick an older generation in the boot menu, then fix the file and rebuild.
