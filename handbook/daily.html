Living with SnapOS

Every change is a line in a file, and every change can be undone.

Changing the system

Open the files with snapos config, change a line, then apply:

snapos diff          # what would change
snapos rebuild       # apply now
snapos rebuild --next-boot   # for kernel and driver changes

A desktop added later is one line in local.nix: snapos.desktop = "plasma";, then snapos rebuild.

Undoing

snapos generations   # the systems you can go back to
snapos rollback      # back to the previous one
snapos gc            # free disk space

Older systems are also in the boot menu.

Updates

At every login SnapOS looks for a new release and newer packages, and offers them. snapos update builds the new system for the next start; if it does not reach the login screen, SnapOS goes back by itself.

SnapGuard and .deb files

snapguard scan ~/Downloads
snapguard status
snap-deb program.deb   # scanned first, then installed in the Debian layer

When something breaks

snapos doctor        # graphics, boot, network and antivirus
snapos log           # the output of the last rebuild
snapos rebuild --trace
