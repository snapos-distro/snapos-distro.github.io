Handbook: Working with SnapOS

Every change is a line in a file, and every change can be undone.

Changing the system

Open the files with snapos config, change a line, then apply:

snapos diff                  # what would change
snapos rebuild               # apply now
snapos rebuild --next-boot   # kernel and driver changes, at the next start

A different desktop is one line in local.nix, for example snapos.desktop = "plasma";, then snapos rebuild.

Undoing

snapos generations   # the systems you can go back to
snapos rollback      # back to the previous one
snapos gc            # free disk space (systems older than 14 days)

Older systems are also listed in the boot menu. In NixOS: nixos-rebuild switch --rollback and nix-collect-garbage.

Updates

At every login SnapOS looks for a new release and for newer packages, and offers them in a window. snapos update builds the new system for the next start; if it does not reach the login screen, SnapOS goes back to the previous one by itself.

SnapGuard and .deb files

snapguard scan ~/Downloads   # scan a folder
snapguard status             # engine and real-time protection
snap-deb program.deb         # scanned, then installed in the Debian layer

When something breaks

snapos doctor            # graphics, boot, network and antivirus
snapos log               # the output of the last rebuild
snapos rebuild --trace   # the full error
