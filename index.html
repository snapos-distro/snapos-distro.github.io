Coming next: a manual image and a universal image (Oct 18, 2026)

SnapOS 2.6 is being built and tested in snapos-test right now. It brings two new images: a manual (minimal) image, where you build your own system the NixOS way and add the SnapOS packs you want, following the handbook; and a universal image, a net install that downloads the newest SnapOS while it installs, so one USB stick keeps installing the latest version.

SnapGuard comes alive (Oct 18, 2026)

Snappy now keeps a cup next to him. A virus that SnapGuard finds falls into it and jumps around, angry. Delete it and Snappy eats it; trust it and it grows wings and flies away. The animations are drawn like Snappy, in ASCII art.

Updates have their own home (Oct 18, 2026)

Installed systems now look for updates in snapos-updates, which only holds what snapos update needs. SnapOS also moved to the snapos-distro organization, and Hyprland is back to plain tiling.

A native Debian layer (Oct 3, 2026)

.deb programs run natively in a Debian layer, like on a real Debian computer, with no sandbox in the way. That is why Steam just works. SnapGuard scans every package before it is installed.
