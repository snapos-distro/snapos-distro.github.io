Carapace installed its first programs (Oct 19, 2026)

The new store works on a real system. In a test machine, Carapace installed Firefox and VSCodium: you click Install, type your password, and it adds the program to /etc/snapos and builds the next system while Snappy climbs a mountain. A few minutes later the program is in the menu, and it can be removed or undone like any other change. Every program in Nix can be installed now, Steam, Discord and Spotify included. Carapace is still being finished in snapos-test: a bigger first page and a faster search come next.

Finally, GNOME Software is leaving! (Oct 19, 2026)

SnapOS is getting its own store: Carapace, named after the turtle's shell. GNOME Software only shows Flatpak apps on SnapOS, so it never really fit. With it, Flatpak and Flathub leave the default system too: they become a pack you can turn on (snapos.packs.flatpak.enable = true;) if you need an app that only Flathub has. Carapace shows the programs from Nix instead, the same ones snapos add installs: popular apps with icons and categories up front, and every one of the Nix packages in the search. Installing adds the program to /etc/snapos and builds the next system, so anything you install can be removed or undone with snapos rollback. While it downloads, Snappy keeps you company: he picks flowers, climbs a mountain, swims, sits by a campfire, goes fishing or flies a kite. It is being built now; this is a preview.

SnapOS 2.6 is here (Oct 18, 2026)

Two new images, with no version in the name. The universal image installs the full SnapOS and, with the internet up, downloads the newest version while it installs. The manual image is a terminal: you build your own system the NixOS way, following the handbook, and turn on the SnapOS packs you want. The NixOS tools now have SnapOS names (snapos-install, snapos-rebuild...) and a system lives in /etc/snapos. Already on SnapOS? Run snapos update. New here? Get the images.

Coming next: a manual image and a universal image (Oct 18, 2026)

SnapOS 2.6 is being built and tested in snapos-test right now. It brings two new images: a manual (minimal) image, where you build your own system the NixOS way and add the SnapOS packs you want, following the handbook; and a universal image, a net install that downloads the newest SnapOS while it installs, so one USB stick keeps installing the latest version.
