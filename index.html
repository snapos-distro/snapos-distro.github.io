What is SnapOS?

SnapOS is a Linux distribution built on NixOS, with an everyday desktop on top. NixOS describes the whole system in one file and can undo any change, but its commands are hard for someone coming from Ubuntu or Debian. SnapOS keeps the habits you already have (search, install, remove, update) under one command, snapos, and shows you the NixOS way behind each one.

Four desktops

Budgie, KDE Plasma, Xfce or Hyprland, in dark or light.

Safe updates

A new system is built for the next start, and SnapOS goes back by itself if it fails.

SnapGuard

A real-time antivirus based on ClamAV.

.deb programs

A native Debian layer, where even Steam runs.
