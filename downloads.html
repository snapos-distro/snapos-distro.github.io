Downloads

Every image is a USB stick image: flash it with balenaEtcher and start the computer from it. Each one has a .sha256 file to check the download.

Releases

Universal (net install)

The installer asks eleven questions (network, keyboard, language, time zone, disk, account, desktop, look, graphics) and installs SnapOS by itself.

x86_64

PCs and laptops with Intel or AMD, BIOS or UEFI
Download
SHA-256 · about 1.9 GB

ARM64

ARM computers that start with UEFI
Download
SHA-256 · about 1.9 GB
The images have no version: with the internet up, the universal image installs the newest SnapOS from snapos-updates, so an old USB stick still installs the latest one. What changed in each version is there too.

Manual (minimal)

A terminal and no installer with questions: you build your SnapOS step by step, the NixOS way. Smaller and closer to how NixOS works.

x86_64

PCs and laptops with Intel or AMD
