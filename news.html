SnapGuard comes alive (Oct 18, 2026)

Snappy now keeps a cup next to him. A virus that SnapGuard finds falls into it and jumps around, angry. Delete it and Snappy eats it; trust it and it grows wings and flies away. The animations are drawn like Snappy, in ASCII art.

Updates have their own home (Oct 18, 2026)

Installed systems now look for updates in snapos-updates, which only holds what snapos update needs. SnapOS also moved to the snapos-distro organization, and Hyprland is back to plain tiling.

A native Debian layer (Oct 3, 2026)

.deb programs run in a Debian layer that works like a Debian computer, with every permission. The protection is SnapGuard, which scans every package before it is installed. Steam works.

The commands people need, under plain names (Sep 27, 2026)

SnapOS 2.4 puts the everyday Nix commands behind snapos: find, add, remove, shell, diff, rollback, generations, gc and more. SnapOS is a bridge from Debian-based distros to NixOS.

SnapOS for ARM64 (Sep 27, 2026)

SnapOS 2.3.1 brought an image for ARM64 computers that start with UEFI, package updates between releases and an installer that can run without questions.

Choose your desktop (Sep 25, 2026)

The installer asks for Budgie, KDE Plasma, Xfce or Hyprland, each in dark or light.

SnapGuard in real time, and updates that cannot break the system (Sep 23, 2026)

SnapOS 2.0 moved to NixOS 26.05 and started to update itself, going back by itself if a new system does not start. 2.1 made SnapGuard watch Downloads and USB drives.

SnapOS 1.0 (Sep 20, 2026)

The first release: the installer, Budgie with the SnapOS look, SnapGuard, SnapWeb and the terminal tools.
